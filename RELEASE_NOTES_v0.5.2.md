# OpenFlux v0.5.2

### Исправления и улучшения транспорта Mail.ru Docs
* **Устранение коллизии сессий (ошибка 4007 `drop`)**: при вызове API `r7/edit` теперь генерируется уникальный адрес `user_<random>@mail.ru`, благодаря чему Mail.ru выдаёт серверу и клиенту независимые ID пользователей и не выбивает сервер из документа при подключении клиента.
* **Полноценное рукопожатие Engine.IO v4**: соблюдён строгий порядок протокола (ожидание открывающего фрейма `0{...}` -> отправка `40{"token":"..."}` -> ожидание ACK `40` -> отправка `42` auth event). Предотвращён сброс соединения сервером с кодом 1005.
* **Корректный статус подключения**: транспорт переходит в состояние `connected = true` только после подтверждения авторизации `{"type":"auth","result":1}` от сервера OnlyOffice.
* **Очистка HTTP Origin**: из заголовка `Origin` удалён путь, оставлены только схема и хост (`https://docs.datacloudmail.ru`).
* **Обработка пачек курсоров**: добавлено множественное извлечение курсоров (`extractAllBase64Strings`), предотвращающее потерю пакетов при совместном редактировании.
* **Видимые логи**: ключевые события жизненного цикла (`[M-DOCS] WebSocket dial`, `[M-DOCS] Auth OK`, `[EXIT] <ip:port> connected`) выводятся в стандартный лог `journalctl`.
