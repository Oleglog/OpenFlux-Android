# OpenFlux Android v1.0.4 / Server Update

## Ключевые изменения и исправления

### 1. Автоматический обход Яндекс SmartCaptcha и стабилизация Volga
- Добавлен встроенный модуль автоматического решения капчи Яндекс (`transport/yandex/captcha.go`).
- Реализован PoW (proof-of-work) солвер для `showcaptchafast`: вычисление хеша, сбор браузерного фингерпринта и автоматическая отправка ответа Яндексу для получения `spravka` без прерывания туннеля.
- Внедрен механизм `dialIPv4First`: принудительный приоритет IPv4 перед IPv6 при обращении к сервисам Яндекса. Это предотвращает рассинхронизацию сессии и бесконечный сброс авторизации на серверах с включенным IPv6.

### 2. Исправление Mail.ru Docs (код 4004 / 409)
- Добавлен обязательный заголовок `Accept-Language: en-US,en;q=0.9` на REST API и WebSocket Upgrade для соответствия поведению современного браузера (устраняет ошибку `409 Conflict`).
- Исправлена передача идентификатора пользователя `user.id: info.EditorUserID` в сообщении авторизации WebSocket `authMsg` для полного соответствия выданному JWT-токену (устраняет ошибку `4004 access deny`).

### 3. Новые транспорты
- **Avito (`avito`, `code.avito.ru`)**: транспорт через платформу онлайн-интервью и совместного редактирования кода Авито (`ShareDB` поверх WebSocket). Высокая надежность и белая российская инфраструктура.
- **Cups.online (`cupsonline` / `cups`, `interview.cups.online`)**: транспорт через платформу IT-чемпионатов и интервью от VK.
- **Telemost (`telemost`)**: нативный транспорт через конференции Яндекс.Телемост с поддержкой многополосного распределения потоков (`StripedTransport`).

### 4. Автоматическое определение транспортов в клиенте и на сервере
- Автодетекция ссылок на документы и комнаты:
  - `mail.ru` -> транспорт `mailru`
  - `avito.ru` -> транспорт `avito`
  - `cups.online` -> транспорт `cupsonline`
  - `telemost.yandex.ru` -> транспорт `telemost`
  - Документы Яндекс -> `vyandex` (Волга) или классический `yandex`
