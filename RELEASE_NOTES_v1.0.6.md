# OpenFlux Android v1.0.6 / Server Update

## Что нового в v1.0.6

### 1. Исправление определения и работы с Яндекс.Документами и Волгой
- **Исправлена ложная классификация Volga (`vyandex`)**: URL вида `https://disk.yandex.ru/i/...` больше не классифицируются ошибочно как Volga. Volga редактор активируется исключительно для ссылок на редактор `/edit/d/` (`https://docs.yandex.ru/edit/d/...`).
- **Публичные ссылки Яндекс.Диска (`disk.yandex.ru/i/...`)**: теперь направляются в классический транспорт `yandex`.
- **Автоматическое прохождение SmartCaptcha в классическом транспорте `yandex`**:
  - Добавлено решение PoW-капчи при HTTP 302 редиректах на `showcaptcha` / `showcaptchafast`.
  - Добавлено автоматическое распознавание и решение PoW-капчи при ответах HTTP 200 OK со страницей `window.__SSR_DATA__` (чекбокс SmartCaptcha).
  - Добавлена поддержка загрузки Netscape cookies (`LoadCookieFile`).

### 2. Обновление протокола Mail.ru Docs
- **Синхронизация с upstream v0.13.0**: протокол Mail.ru переведен с нестабильного канала курсора (cursor) на высокоскоростной широковещательный чат-канал (`OFX1`) с бесшовной ротацией сессий (make-before-break rotation).
- **Защита от ошибки 4004 (access deny)**: R7 сервер Mail.ru имеет лимит ~80-90 сообщений на сессию; автоматическая ротация сессий и пейсинг сообщений предотвращают исчерпание лимита под нагрузкой.
- **Поддержка аутентификации после закрытия анонимного доступа Mail.ru**: на стороне Mail.ru закрыт анонимный API `r7/edit` (`401 FORBIDDEN/ANONYMOUSE/ACCESS`). Поддерживается загрузка cookies из файла (`cookies.txt` или флаг `--cookies /etc/olcrtc/cookies.txt`).
- Полная интеграция с SOCKS5 прокси сигнализации (`--socks-proxy` / `--warp-proxy`).

### 3. Новый транспорт Bitrix24 (`bitrix24`)
- Добавлен транспорт через чат-сообщения порталов Bitrix24 (`*.bitrix24.ru`).
- Домены `*.bitrix24.ru` находятся в «белых списках» большинства российских провайдеров и обеспечивают устойчивый канал связи.
- Поддерживается пакетная передача сообщений (batch writer) и авто-создание чата.

### 4. Версионирование
- Android клиент обновлен до `v1.0.6` (versionCode 14).
- Бинарные релизы сервера OpenFlux Linux (amd64, arm64).
